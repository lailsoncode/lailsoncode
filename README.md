## ⚙️ Conhecimentos Técnicos Avançados

Adquiridos na construção do **MeAgende.me** — SaaS multi-tenant em produção:

**🔐 Segurança & Multi-Tenancy Real**
Arquitetura com isolamento total por unidade via **Row-Level Security (RLS)** avançado no PostgreSQL. Sistema de roles (`master_admin`, `shop_admin`, `barber`, `customer`, `reseller`) com função `has_role()` aplicada nas policies — segurança por design, não por convenção.

**⚡ Backend Serverless com Deno (Edge Functions)**
+40 Edge Functions no Supabase (runtime Deno) cobrindo: pagamentos (Stripe + Mercado Pago webhooks e split), automação WhatsApp (lembretes, retenção, campanhas), faturamento SaaS automatizado com cron jobs, geração de imagens com IA e gateway de comunicação com Vertex AI.

**📡 Real-time & Cache Assíncrono**
Sincronização em tempo real via `postgres.changes` (Supabase Realtime) combinado com cache inteligente do **TanStack React Query v5** — arquitetura que elimina polling e garante UI sempre consistente.

**💰 Lógica Financeira Complexa**
Motor de caixa com pagamentos mistos e fracionados (N formas de pagamento por transação), cálculo automático de taxas de maquininha por bandeira, comissionamento líquido por barbeiro e reconciliação de invoices Stripe contra registros internos.

**📱 Web → Mobile com Capacitor**
Mesma codebase React gerando **PWA + APK Android + iOS**, com builds automatizados via Codemagic CI/CD e dois bundles Vite distintos (painel admin e app do cliente).

**🤖 IA Conversacional em Produção**
Deploy de Reasoning Engine no **Google Cloud Vertex AI** (Python SDK), integrado ao produto via Edge Function como gateway — agente MIA respondendo clientes em tempo real.

**💳 Integrações de Pagamento Complexas**
Stripe (Checkout Sessions, Webhooks, Subscriptions, reconciliação automática) + Mercado Pago (Pix dinâmico, split de pagamentos para revendedores, webhooks assíncronos).
